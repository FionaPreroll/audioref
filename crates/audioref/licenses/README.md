# Standard license texts

The about window shows the license texts of the crates AudioRef is built with. A few crates, e.g. egui's, publish no license file: for them `build.rs` takes the standard text of their license from here, with their name and authors. The texts are the licenses' own: `MIT.txt` as serde publishes it, `Apache-2.0.txt` as addr2line does, `ISC.txt` as nih-plug does, without its copyright line.
